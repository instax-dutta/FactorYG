## Purpose

Own the Factor-I superpowers documentation subtree.

## Ownership

- `specs/` contains approved design specifications.
- `plans/` contains executable TDD implementation plans.

## Local Contracts

- Documentation must match implemented behavior and the active plan.
- Stable paths and explicit verification commands are preferred.
- Temporary research notes and secrets do not belong in this tree.

## Work Guidance

- Update the nearest owning document when contracts change.
- Keep the source specification at `factor-y-2d-spec.md` as the product baseline.

## Verification

- No documentation-only test command is defined.
- Run the repository verification commands listed in the active plan when documentation accompanies code.

## Child DOX Index

- `specs/AGENTS.md` - approved design specifications.
- `plans/AGENTS.md` - task-level implementation plans.
